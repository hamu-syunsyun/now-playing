Spotifyとつなぐ

  1. Spotify for Developers のダッシュボードを開き、 いつものアカウントでログインして「Create app」を押す。アプリ名と説明は何でもかまいません。
  2. 「Redirect URIs」に下のアドレスを入れて Add を押す。使うAPIは「Web API」にチェック。
  3. 保存したらアプリの画面に出る Client ID をここに貼る。

Client ID とログイン情報はこのブラウザの中だけに保存されます。見た目だけ先に試す
